# 課堂錄影筆記整理 SOP

本文件定義「課堂錄影與影音檔（配合參考文本）整理為 Obsidian 筆記」的標準工作流程。

## 適用時機
當用戶提供任何課堂、研習或讀書會的錄影/錄音檔案路徑，或要求整理某堂課的筆記時。

## 核心處理流程

### 第一步：音視訊前處理（若需要）
* **無聲段剪切**：若用戶提及影片後段有冗餘無聲片段，使用 `ffmpeg` 配合 `silencedetect` 偵測靜音起點，並以 `-c copy` 無損且快速剪切，輸出 trimmed 檔案。

### 第二步：內容讀取（優先使用 NotebookLM）
* **憑證刷新**：每次查詢前，呼叫 `refresh_auth` 刷新存取憑證。
* **尋找筆記本**：呼叫 `notebook_list` 找出與該課程主題最相關的 Notebook ID。
* **結構化查詢**：呼叫 `notebook_query`。查詢時應明確提供參考文本，要求 NotebookLM 將音檔內容、案例與概念解釋做最詳盡的提取。

### 第三步：筆記結構與寫作風格規範
* **標題層級**：以 `## 一、`、`## 二、` 等二級標題劃分主軸，段落內以條列 `*` 展開。
* **重點標註**：使用 `**粗體**` 標示核心觀念、專業名詞與關鍵結論。
* **概念拆解**：遇到深奧理論、學科概念或複雜公式/條文時，使用三級標題 `### 【概念拆解】[主題名稱]` 進行專題剖析。
* **原文與條文排版**：課堂提及的經典原文或條文，需以獨立的粗體條列或專區完整列出。

### 第四步：寫入路徑與確認機制
* **紫林中醫基礎課**：
  * 統一寫入 / 增補至：[紫林中醫基礎課四五六單元.md](file:///G:/我的雲端硬碟/Obsidian/sshorng/04第二大腦/紀錄資料庫/學習/紫林中醫基礎課四五六單元.md) 的對應日期標題下（例如 `# YYYY-MM-DD單元X：[名稱]`）。
* **非紫林中醫基礎課（其他所有課堂）**：
  * **必須先詢問用戶**：「此課堂不屬於紫林中醫基礎課，請問是否需要為此課程單獨建立一個全新的 `.md` 筆記檔？或是有指定的存放路徑與檔名？」

### 第五步：日誌同步
* 整理完畢後，即時將執行成果記錄於今日工作日誌 `000_Agent/memory/daily/YYYY-MM-DD.md`。
