     - **Proxy.gs 簽章驗證優化與平台限制處置**：原預計加入 LINE Webhook 簽章驗證，但經實測，Google Apps Script (GAS) 部署為 Web App 時其執行環境並不會傳遞 HTTP Headers（`e.headers` 為 `undefined`），導致簽章比對一律失敗使服務停止回應。為此，已緊急移除簽章驗證邏輯，以維持正常服務運作。

     - **Obsidian.gs 檢索效能提升**：實作 `CACHED_OBSIDIAN_FOLDER_ID` 快取，讓 Obsidian 資料夾獲取跳過逐層遞迴搜尋；重構 `getFileByName`，採用 Drive 伺服器端過濾篩選變量檔案代替全量 getFiles() 遍歷，解決大檔案量下的 API 延遲與 Google 限流。
