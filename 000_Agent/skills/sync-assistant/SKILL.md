# 自動同步與備份助手 (`/sync`)

當使用者輸入 `/sync` 或提及「同步」、「推送」、「git備份」、「寫日誌」、「下班」、「完工」時，自動執行以下標準作業流程：

---

## 執行流程

### Phase 1：更新今日工作日誌
1. **取得今日日期**：以 `YYYY-MM-DD` 格式為檔案名稱（例如：`2026-06-04.md`）。
2. **定位日誌路徑**：`G:\我的雲端硬碟\AI_Agent\000_Agent\memory\daily/YYYY-MM-DD.md`。
3. **讀取/建立日誌**：
   - 若該檔案已存在，先讀取其內容，**僅以「追加/增量補充」方式寫入新內容，嚴禁刪除或覆寫舊的紀錄**。
   - 若不存在，則建立新檔案。
4. **寫入內容結構**：
   ```markdown
   # YYYY-MM-DD 工作日誌

   ## 關鍵決策與變更
   - [描述今日關鍵變更]

   ## 完成任務
   - [x] [任務名稱]

   ## 待辦/後續任務
   - [ ] [待辦名稱]
   ```

### Phase 2：更新全域記憶 (若有)
- 檢查本次對話是否產生了新的使用者偏好、技術踩坑或習慣。若有，將其追加至 `000_Agent/memory/MEMORY.md` 的對應區塊中。

### Phase 3：Git 自動化備份與推送
1. **檢查 Git 狀態**：在 `G:\我的雲端硬碟\AI_Agent\` 目錄下執行 `git status`。
2. **暫存所有變更**：執行 `git add .`。
3. **自動生成 Commit 訊息**：
   - 格式為：`style/feat/fix: [繁體中文簡短描述變更]`
   - 例如：`feat: 實作自動同步技能與修正全域人設`
4. **提交變更**：執行 `git commit -m "<commit_message>"`。
5. **推送到遠端倉庫**：執行 `git push`。

### Phase 4：完成回報
- 向使用者匯報日誌更新的檔案連結與 Git Commit/Push 狀態。
