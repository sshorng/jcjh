# SOIL 雙定位分析技能 (SOIL-inspired Dual Positioning Analysis)

本技能旨在協助教師將任何一段文本、演講稿、教材、課程內容、文章、教案或案例，進行深度的「核心概念定位」與「教學脈絡定位」。其目標非單純摘要內容，而是找出材料背後真正可教學、可遷移、可視覺化的概念關係，並將分析結果轉化為易於製作成 16:9 簡報圖解的文字描述。

---

## 1. 核心原則

### 1.1 核心概念先行
所有分析都必須回到核心概念。不可只整理材料內容，也不可只做摘要。必須找出材料中可教學、可遷移、可視覺化的概念關係。

### 1.2 認知一致性
WHAT、WHY、HOW、核心概念句、教學脈絡、遷移情境與圖像化描述之間必須保持一致。
避免以下問題：
- WHAT 分析的是 A，WHY 卻變成 B。
- WHY 萃取出三個概念，但核心概念句使用新的概念。
- 核心概念句談的是一件事，教學脈絡卻換成另一件事。
- 核心概念句談的是一件事，遷移情境卻換成另一組邏輯。
- 圖像化建議只是漂亮整理，卻沒有呈現概念關係。

### 1.3 結構映射
跨情境遷移時，不是任意更換例子，而是保留原始核心概念中的關係結構。不同情境可以改變表面內容，但不可改變三個 WHY 之間的底層關係。

### 1.4 三圖功能區分
輸出時要區分三種圖的功能：
- **圖一：核心概念定位圖**
  - 回答：這份材料的核心概念是什麼？
  - 呈現：WHAT 主題事實、WHY 關鍵概念、HOW 技能表現，如何共同指向核心概念。
- **圖二：教學脈絡定位圖**
  - 回答：這個核心概念要怎麼教？
  - 呈現：核心概念如何轉化為「引起動機、維持注意、喚起行動」的教學流程。
- **圖三：核心概念遷移表圖**
  - 回答：這個核心概念可以用到哪些其他情境？
  - 呈現：同一組 WHY 關鍵概念如何在不同情境中維持結構一致，但展現不同內容。

## 2. 分析與輸出流程

請依照以下順序與格式進行完整輸出。

### 第一部分：材料初步判讀
請先用一小段文字說明這份材料的主要脈絡。
- **引導問題**：
  - 這份材料表面上在談什麼？
  - 它背後真正想讓學習者理解什麼？
  - 它可能不是只要教什麼，而是要幫助學習者形成什麼判斷、理解或行動？
- **要求**：字數約 150 至 250 字，精煉到位。

### 第二部分：核心概念定位
使用 WHAT、WHY、HOW 進行分析，分析順序為：**WHAT 主題事實 → WHY 關鍵概念 → HOW 技能表現 → 核心概念句**。

#### 2.1 WHAT：主題事實
找出三個主要主題事實。回答：這份材料主要說了哪些重要內容？（避免瑣碎摘要，抓出能支撐核心概念的主要內容）
- **格式**：
  | 層次 | WHAT 主題事實說明 |
  | :--- | :--- |
  | WHAT 1 | [具體內容] |
  | WHAT 2 | [具體內容] |
  | WHAT 3 | [具體內容] |

#### 2.2 WHY：關鍵概念
找出三個最重要的關鍵概念。回答：這份材料背後真正重要、可遷移、可教學的概念是什麼？（注意：WHY 不是主題名稱，而是可遷移的關鍵概念，作為核心概念句、教學脈絡與遷移表格的底層結構）
- **格式**：
  | 層次 | WHY 關鍵概念說明 |
  | :--- | :--- |
  | WHY 1 | [關鍵概念與說明] |
  | WHY 2 | [關鍵概念與說明] |
  | WHY 3 | [關鍵概念與說明] |

#### 2.3 HOW：技能表現
找出三個學習者應形成的理解、判斷、操作或應用能力。回答：學習者學完後，應該能理解、判斷、應用或實踐什麼？（非活動名稱，而是學習者可展現的能力）
- **格式**：
  | 層次 | HOW 技能表現說明 |
  | :--- | :--- |
  | HOW 1 | [技能表現說明] |
  | HOW 2 | [技能表現說明] |
  | HOW 3 | [技能表現說明] |

#### 2.4 WHAT、WHY、HOW 對應表
將三者整理成對應關係，確保每一列的 WHAT、WHY、HOW 有清楚對應，能支撐後續核心概念句。
- **格式**：
  | WHAT 主題事實 | WHY 關鍵概念 | HOW 技能表現 |
  | :--- | :--- | :--- |
  | WHAT 1 | WHY 1 | HOW 1 |
  | WHAT 2 | WHY 2 | HOW 2 |
  | WHAT 3 | WHY 3 | HOW 3 |

### 第三部分：核心概念句

#### 3.1 A1 核心概念句：關係主張
根據上述分析，提出一到三句核心概念句。請分成三種版本：
- **格式**：
  | 版本 | 核心概念句 |
  | :--- | :--- |
  | 學術精準版 | [內容] |
  | Teaching簡報版 | [內容] |
  | 感性金句版 | [內容] |

#### 3.2 嚴格條件
1. 必須是一個可被運算的「關係主張」。
2. 必須直接使用並串聯上述提煉出的三個 WHY。
3. 必須清楚指出三個 WHY 之間的因果、條件、轉化或連動關係。
4. 不可偏離三個 WHY 自行發明新的主軸，不可寫成主題式標語（如「逆境中的成長」）。
- **參考句型**：
  - *WHY 1 會改變 WHY 2，進而影響 WHY 3。*
  - *當 WHY 1 發生時，若能透過 WHY 2 的作用，便可能形成 WHY 3。*
  - *真正的成長，是在 WHY 1 中透過 WHY 2，最後走向 WHY 3。*

#### 3.3 最建議採用版本
選出一個「最建議採用版本」，並簡短說明理由。
- **格式**：
  | 最建議版本 | 理由 |
  | :--- | :--- |

### 第四部分：核心概念定位圖
根據前面的分析與核心概念句，產出一段可以轉成 16:9 簡報圖解的文字描述。呈現 WHAT、WHY、HOW 如何共同指向核心概念。

#### 4.1 核心概念定位圖文字描述格式
- **圖片標題**：[標題]
- **左側核心概念框**：
  - 核心概念句：[最建議採用版本]
- **中央結構**：
  - **WHAT**：列出三個主題事實
  - **WHY**：列出三個關鍵概念（置於中央，作為 WHAT 與 HOW 之間的概念中介）
  - **HOW**：列出三個技能表現
- **視覺關係**：
  - WHAT、WHY、HOW 以括號或連線整合。WHY 位於中間。
  - 左側核心概念框（由 WHY 關係主張形成）以箭頭或連線連到中央 WHY。
- **色彩建議**：核心概念與 WHY 使用紅色或深色強調，WHAT 與 HOW 使用灰色區塊呈現。
- **版面風格**：16:9 極簡教學簡報風格，大字、少字、強調結構關係。

#### 4.2 圖像限制
此圖非摘要圖，必須清楚呈現 WHY 如何成為核心概念句的關係骨架。不可只將文字排成三欄，須說明三者如何共同指向核心概念。

### 第五部分：教學脈絡定位
將核心概念轉化為三階段教學設計：**引起動機（創造需求）→ 維持注意（建構概念）→ 喚起行動（總結延伸）**。

#### 5.1 Teaching脈絡總表
- **格式**：
  | 教學階段 | 教學功能 | 對應內容 | 對應 WHY | 教學目的 |
  | :--- | :--- | :--- | :--- | :--- |
  | 引起動機 | 創造需求 | [教材對應點] | WHY X | [目的] |
  | 維持注意 | 建構概念 | [教材對應點] | WHY Y | [目的] |
  | 喚起行動 | 總結延伸 | [教材對應點] | WHY Z | [目的] |

#### 5.2 三階段詳細說明
- **格式**：
  - **第一階段：引起動機**
    - 核心任務：[任務說明]
    - 對應內容：[內容]
    - 對應 WHY：[WHY]
    - 可提問問題：[提問]
    - 教學策略：[策略]
    - 銜接方式：[銜接下階段的做法]
  - **第二階段：維持注意**
    - 核心任務：[任務說明]
    - 對應內容：[內容]
    - 對應 WHY：[WHY]
    - 可提問問題：[提問]
    - Teaching策略：[策略]
    - 銜接方式：[銜接下階段的做法]
  - **第三階段：喚起行動**
    - 核心任務：[任務說明]
    - 對應內容：[內容]
    - 對應 WHY：[WHY]
    - 可提問問題：[提問]
    - 教學策略：[策略]
    - 銜接方式：[銜接做法]

#### 5.3 教學脈絡一句話總結
- **格式**：以＿＿引發＿＿，以＿＿建構＿＿，以＿＿喚起＿＿。
- **要求**：必須對應三個教學階段與三個 WHY，回扣核心概念句。

### 第六部分：教學脈絡定位圖
產出教學脈絡定位圖（16:9 簡報）的文字描述。呈現核心概念如何轉化為引起動機、維持注意、喚起行動的課程設計流程。

#### 6.1 教學脈絡定位圖文字描述格式
- **圖片標題**：[標題]
- **中央核心概念**：[核心概念]
- **右側或上方補充概念**：[如：啟發性、可遷移性等]
- **上方結構**：WHY / WHAT / HOW 對應關係
- **三階段流程**：
  - **引起動機**：教學功能、對應 WHY、學習者要看見、可用策略
  - **維持注意**：教學功能、對應 WHY、學習者要理解、可用方法
  - **喚起行動**：教學功能、對應 WHY、學習者要行動、可用工具
- **下方教學設計層**：教學策略、教學方法、教學工具
- **視覺關係**：上方以核心概念統整 WHY、WHAT、HOW。中段以三個彩色區塊（引起動機：橘色、維持注意：紫色、喚起行動：綠色）呈現流程，並以箭頭連接。下方以策略、方法、工具作為支撐。
- **版面風格**：16:9 極簡教學簡報流程圖，大字、少字、清楚連線。

#### 6.2 圖像限制
必須呈現「核心概念 → 教學三階段 → 教學策略／方法／工具」的關係。三階段都必須回扣核心概念句，展現為何此安排能幫助學生理解核心概念。

### 第七部分：核心概念的遷移性：結構映射
將第一部分找出的三個 WHY 作為底層結構，映射到至少四個不同的新情境中，以確保跨情境的認知一致性。

#### 7.1 核心概念遷移表
- **格式**：
  | 核心概念 | 原始材料 | 映射情境一：[名稱] | 映射情境二：[名稱] | 映射情境三：[名稱] | 映射情境四：[名稱] |
  | :--- | :--- | :--- | :--- | :--- | :--- |
  | **WHY 1**：[名稱] | [原始表現] | [情境一表現] | [情境二表現] | [情境三表現] | [情境四表現] |
  | **WHY 2**：[名稱] | [原始表現] | [情境一表現] | [情境二表現] | [情境三表現] | [情境四表現] |
  | **WHY 3**：[名稱] | [原始表現] | [情境一表現] | [情境二表現] | [情境三表現] | [情境四表現] |
  | **關係統整**（或自訂名稱）| [原始關係句] | [情境一關係句] | [情境二關係句] | [情境三關係句] | [情境四關係句] |

#### 7.2 最後一列命名規則
最後一列可依教材性質命名，如「系統穩固」、「遷移理解」、「概念統整」、「關係主張」、「行動轉化」、「價值判斷」、「解題框架」、「教學轉化」、「生命理解」、「公共回應」、「調節理解」等。預設為「關係統整」。

#### 7.3 表格填寫與句型要求
1. 每一格必須對應該列的 WHY，不可混入其他概念，亦不可新增第四個 WHY。
2. 最後一列必須是統整該情境下三個 WHY 的一句關係主張，而非標語或摘要。
3. 可使用句型：
   - *在【情境名稱】中，當 WHY 1 出現時，若能透過 WHY 2 的作用，便能形成 WHY 3。*
   - *在【情境名稱】中，WHY 1 會影響 WHY 2，進而改變 WHY 3。*
   - *在【情境名稱】中，真正的表現／成長，是在 WHY 1 中透過 WHY 2，最後走向 WHY 3。*

#### 7.4 遷移性說明
在表格後補上一段文字，說明這三個 WHY 之間形成了什麼關係結構？為什麼此結構可以跨情境遷移？學習者掌握此結構後，如何將知識轉用到新情境？（必須回到三個 WHY 之間的關係來說明）

### 第八部分：核心概念遷移表圖
產出核心概念遷移表圖的 16:9 簡報文字描述。

#### 8.1 核心概念遷移表圖文字描述格式
- **圖片標題**：[標題]
- **橫軸**：各情境名稱（情境一至四）
- **縱軸**：WHY 1、WHY 2、WHY 3、關係統整列（名稱可依教材調整）
- **表格內容**：對應遷移表，最後一列用較深底色或較粗橫線與前三列區隔，呈現三個 WHY 在該情境中如何組成一句完整的關係主張。
- **視覺關係**：縱向閱讀呈現同一個 WHY 如何在不同情境中轉換；橫向閱讀呈現同一情境中三個 WHY 如何共同運作並在最下方組合成核心概念句。
- **色彩建議**：情境標題藍色，WHY 1-3 紅色，最後一列深紅色或粗體，內容深灰色。
- **版面風格**：16:9 極簡表格，大字、少字、清楚對齊。

### 第九部分：三圖關係說明
用一段話說明三張圖之間的關係：
> 「核心概念定位圖」處理**概念如何被定位**（材料轉成概念）；「教學脈絡定位圖」處理**概念如何被教學化**（概念轉成教學）；「核心概念遷移表圖」處理**概念如何被遷移**（概念轉成跨情境應用）。

### 第十部分：品質檢核
最後請檢附品質檢核表，確保滿足所有規範。
- **格式**：
  | 檢核項目 | 是否達成 | 簡要說明 |
  | :--- | :---: | :--- |
  | WHAT、WHY、HOW 是否彼此對應 | | |
  | WHY 是否位於核心概念句的結構中心 | | |
  | 核心概念句是否直接串聯三個 WHY | | |
  | 核心概念句是否為關係主張 | | |
  | 教學脈絡是否回扣核心概念句 | | |
  | 教學脈絡圖是否呈現核心概念如何被教學化 | | |
  | 遷移表格是否以三個 WHY 作為底層結構 | | |
  | 遷移表格最後一列是否統整三個 WHY 的關係 | | |
  | 不同情境是否維持結構映射 | | |
  | 三張圖像化描述是否呈現不同功能 | | |
  | 是否避免只做內容摘要 | | |

## 3. 觸發與輸入情境

當使用者輸入以下任一種需求，或含有類似語意時，應優先載入並啟用本技能：
- "請幫我進行核心概念定位"
- "請幫我進行教學脈絡定位"
- "請幫我分析這份教材"
- "請幫我找出這篇文章的核心概念"
- "請幫我做核心概念的遷移性分析"
- "請幫我產出三張圖的文字描述"
- "請根據以下材料做雙定位分析"

> [!NOTE]
> 若使用者僅要求完成其中一部分（例如只要「核心概念定位」），請優先完成該部分，但仍須維持 WHAT、WHY、HOW 與核心概念句之間的認知一致性。
