# 課堂沉浸式遊戲簡報產生器 (Class Game Builder)

本技能旨在為國中國文教師「夫子」快速將課文或講義，生成為具備「沉浸式劇情情境」、「高互動與趣味性」且**兼具「深度文本探討（文意理解與寫作手法）」**的高品質單檔 HTML 網頁簡報遊戲。

---

## 🎯 核心設計哲學：趣味互動與深度文本並重
生成遊戲簡報時，必須取得以下平衡，絕不可做成膚淺的遊戲：
1. **趣味與高互動性**：利用劇情帶入、角色切換與數值量表，引導學生融入情境，保持高度專注。
2. **深度文本探討（核心靈魂）**：所有互動關卡的內核必須緊扣**「文意理解」**與**「寫作手法」**的解析。
   - *例如*：不問無意義的劇情瑣事，而是讓學生探討「為什麼作者要安排這段對話？」、「點選最關鍵的神態詞語」，讓學生在進行決策與探索的過程中，學會如何解讀文學作品的寫作技巧。

---

## 📐 16:9 版面與 CSS 核心規範
為了確保投影與平板上的視覺美感，版面必須嚴格遵守以下大字自適應排版系統：

### 1. 外框鎖定 16:9 比例
外層大容器 `.slide-container` 必須嚴格鎖定比例，不被內容撐大變形：
```css
.slide-container {
    width: 96vw;
    height: 54vw; /* 鎖定 16:9 寬高比 */
    max-width: 177.78vh;
    max-height: 90vh; /* 貼合螢幕邊緣 */
    background-color: #050505;
    border: 3.5px solid #444;
    position: relative;
    z-index: 10;
    display: flex;
    flex-direction: column;
    justify-content: space-between;
    padding: 2.2vh 4vw;
    border-radius: 12px;
    overflow: hidden; /* 保持外框穩定 */
}
```

### 2. 消除多餘留白與自適應下拉滾動
中間內容區 `.slide-body` 必須自動分配剩餘空間，吃掉多餘的留白，並在內容過多時在內部產生垂直滾動條：
```css
.slide-body {
    flex: 1; /* 自動填滿 header 與 footer 之間的所有空間，徹底消除上下無用留白 */
    height: 0; /* 配合 flex 確保內容不會撐大 16:9 外框 */
    display: flex;
    flex-direction: column;
    justify-content: flex-start;
    overflow-y: auto; /* 內容超出時，在中間內容區內產生滾動，實現下拉 */
    z-index: 2;
    padding-right: 0.8vw;
    margin-bottom: 1.5vh;
}
```

## 🗺️ 多文體適應之核心互動關卡模組指南
為了適應國中國文的多元文體，AI 助理在設計遊戲關卡時，應針對不同文體採用最契合的互動模組：

### 1. 記敘文 / 小說類（情節起伏與人物刻畫）
* **焦點**：衝突發展、人物心境、寫作波瀾。
* **關卡模組設計**：
  - **心境/立場對立卡片**：讓學生點選對比兩大陣營或人物的心理反應（如：眾官之恐 vs 孔明之定），體會「襯托法」。
  - **心理/危機數值量表**：事件緊張度或心防變化的進度條（如：空城計中的「伏兵疑慮值」、背影中的「酸楚指數」）。
  - **寫作妙處探索按鈕**：引導思考「為什麼要在這裡安插這個插曲/段落？」，探索【情節張力】、【側面烘托】等作用。
  - **字詞尋寶**：在原文中點選「動作特寫」或「神態特寫」的關鍵字眼（如：笑容可掬、旁若無人）。

### 2. 抒情文類（借景抒情、情感投射與象徵）
* **焦點**：意象象徵、情感波動、情景交融。
* **關卡模組設計**：
  - **借物抒情解碼鏡**：左右對比「景物/象徵物（實）」與「內在情感（虛）」（如：紙船 ➔ 母親的愛、蓮花 ➔ 君子的操守）。
  - **意象尋寶點選**：在課文中點選「最能觸發情感波動」或「具象徵意義」的段落或疊字，點對解鎖情感轉折賞析。
  - **情懷心路地圖**：隨著空間轉移（如：遊記、回憶空間），點擊地圖上的地標，解鎖作者在不同地點的情感起伏。

### 3. 說明文類（說明方法、結構邏輯與順序）
* **焦點**：說明手法、結構組織、邏輯順序。
* **關卡模組設計**：
  - **智慧解碼匹配卡**：將「說明對象」與其「特徵、原理」進行點選匹配（如：大自然的各種規律與科學解碼）。
  - **步驟進度條量表**：若文章介紹製作流程或演變順序，設計步驟解鎖進度條。
  - **說明手法尋寶**：在課文中點選辨識「舉例說明」、「數據說明」、「比較說明」的段落，答對解鎖說明美學分析。

### 4. 議論文類（論點攻防與論證邏輯）
* **焦點**：論點、論據、論證結構。
* **關卡模組設計**：
  - **說服力指數量表**：模擬一場「觀點攻防戰」，當點對強力的論據時，「說服力進度條」隨之上升至 100%。
  - **論據尋寶匹配**：給出一個核心論點（如：雅量），讓學生在段落中點選找出支持該論點的「事實論據」或「理論論據」。
  - **正反思辨對照卡**：對比「正方論證」與「反方駁論」，點選體會論證的嚴密性與寫作上的「對比效果」。

### 5. 新詩 / 古典詩歌類（意象意境與聲律修辭）
* **焦點**：意象雙向解碼、修辭美學、聲韻節奏。
* **關卡模組設計**：
  - **詩句重組/押韻尋寶**：打亂詩句順序讓學生重組，或點選出「押韻字」、「借代詞」，答對觸發精美的金色字體展開動畫。
  - **意象解碼卡**：對照「詩歌中的意象（如：牽牛星）」與其「象徵的憂愁/距離」，解析詩歌的含蓄之美。

## 📖 國文寫作手法規範（修辭考點鐵律）
在撰寫任何寫作分析時，必須使用嚴謹、地道的國中修辭考點，**嚴禁使用非教材觀念的「以動襯靜」**：
1. **對比法**：分析多寡對比、虛實對比、忙閒對比、正反對比。
2. **襯托法**：
   - **反襯**：以對立面的慌亂/負面狀態，反襯主角的鎮定/正面狀態。
   - **正襯**：以配角/環境的從容/正面狀態，正襯主角的氣定神閒。

## 🎵 音效免檔案錯誤規範
使用 Web Audio API 生成音效，不依賴外部檔案，防範執行錯誤：
```javascript
function playQinSound(frequency) {
    if (!window.AudioContext && !window.webkitAudioContext) return;
    const ctx = new (window.AudioContext || window.webkitAudioContext)();
    const osc = ctx.createOscillator();
    const gain = ctx.createGain();
    osc.connect(gain);
    gain.connect(ctx.destination);
    osc.frequency.value = frequency;
    osc.type = 'sine';
    gain.gain.setValueAtTime(0.15, ctx.currentTime);
    gain.gain.exponentialRampToValueAtTime(0.01, ctx.currentTime + 0.8);
    osc.start();
    osc.stop(ctx.currentTime + 0.8);
}
```

## 🚀 交付流程
當觸發此技能時，請依照下列步驟進行：
1. 深入閱讀用戶提供的課文/大綱，判斷文體並提煉出 **3-5 個兼具文意理解與寫作美學的深度情境關卡**。
2. 規劃關卡設計：確定哪些頁面使用角色卡心境對照、點詞尋寶、量表沙盤、或寫作妙處探索。
3. 仿照 `empty-fort.html` 的 16:9 排版架構，生成完整的單檔 HTML 檔案。
4. 執行 HTML 全域 `<div>` 標籤平衡檢測，確保無破損。
5. 部署並提供檔案庫網址與 Pages 預覽網址。
