# 課堂沉浸式遊戲簡報產生器 (Class Game Builder)

本技能旨在為國中國文教師「夫子」快速將課文或講義，生成為具備「沉浸式劇情情境」、「高互動與趣味性」且**兼具「深度文本探討（文意理解與寫作手法）」**的高品質單檔 HTML 網頁簡報遊戲。

---

## 🎯 核心設計哲學：動態提取知識點，拒絕範本套死
AI 助理在接收到夫子提供的課文與講義時，必須遵循**「動態分析、知識提取、量身設計」**原則，絕不可套用固定的寫作手法或僵化的關卡模組：

1. **動態提取核心知識點**：
   - 仔細研讀用戶提供的**講義、備課資料、或課文**。
   - 從中提煉出該課真正要傳授的**核心文意理解**、**關鍵寫作手法/修辭**、以及**段落解析知識點**。
   - 所有關卡與解析文字必須完全圍繞這些「提取出來的知識點」來建構。

2. **關卡與互動模組靈活設計**：
   - 根據提取出的知識點，動態挑選或自訂最合適的互動方式（點選、分欄、數值變化、地圖、卡片對照等）。
   - **拒絕套死模組**：可自由調整、組裝或創造全新的互動版面，只要其能最直觀地呈現該知識點的文學美感與趣味性。

3. **趣味互動與深度文本並重**：
   - 所有互動機制的內核必須是「文本探討（文意與手法）」。讓學生在點擊、抉擇或探索的趣味互動中，自然吸收並理解提取出來的國文知識點。

## 📐 16:9 版面與 CSS 核心規範
為了確保投影與平板上的視覺美感，版面必須嚴格遵守以下大字自適應排版系統：

### 1. 外框鎖定 16:9 比例
外層大容器 `.slide-container` 必須嚴格鎖定比例，不被內容撐大變形：
```css
.slide-container {
    width: 96vw;
    height: 54vw; /* 鎖定 16:9 寬高比 */
    max-width: 177.78vh;
    max-height: 90vh; /* 貼合螢幕邊緣 */
    background-color: #050505;
    border: 3.5px solid #444;
    position: relative;
    z-index: 10;
    display: flex;
    flex-direction: column;
    justify-content: space-between;
    padding: 2.2vh 4vw;
    border-radius: 12px;
    overflow: hidden; /* 保持外框穩定 */
}
```

### 2. 消除多餘留白與自適應下拉滾動
中間內容區 `.slide-body` 必須自動分配剩餘空間，吃掉多餘的留白，並在內容過多時在內部產生垂直滾動條：
```css
.slide-body {
    flex: 1; /* 自動填滿 header 與 footer 之間的所有空間，徹底消除上下無用留白 */
    height: 0; /* 配合 flex 確保內容不會撐大 16:9 外框 */
    display: flex;
    flex-direction: column;
    justify-content: flex-start;
    overflow-y: auto; /* 內容超出時，在中間內容區內產生滾動，實現下拉 */
    z-index: 2;
    padding-right: 0.8vw;
    margin-bottom: 1.5vh;
}
```

## 🗺️ 多維度知識點互動生成指引
AI 應根據提取出的知識點性質，靈活設計與其最契合的動態互動版面：

### 1. 「人物心理/情勢轉折」類知識點
* **適用互動**：雙向立場對照卡片、心理量表進度條、角色主客觀視角切換等。
* **設計原則**：讓學生點選觀察人物在情境事件下的心理變化或外在情勢轉折，隨後揭示深度賞析。

### 2. 「寫作手法/文學評論」類知識點
* **適用互動**：大導演視角分鏡點選、寫作插曲之思考探索按鈕、寫作妙處三維度（情節、人物、烘托）解析等。
* **設計原則**：引導學生站在「作家」的思維，探討「為什麼要重複描寫？」、「為什麼要安插這個段落？」，將靜態分析轉化為思維挑戰。

### 3. 「核心意象/象徵隱喻」類知識點
* **適用互動**：實虛解碼鏡、核心象徵點選解密、意象空間軌跡解鎖等。
* **設計原則**：對比景物/實物與其內在情感/抽象理念的關聯，引導學生自主解碼意象。

### 4. 「字詞精鍊/神態細節」類知識點
* **適用互動**：原文高亮點選尋寶、字詞挖空比對驗證等。
* **設計原則**：在課文段落中用 `<span>` 包裹字詞，由學生點選找出最關鍵的神態詞、最精鍊的動詞等，點對解鎖精細文字美學析論。

### 5. 「論證邏輯/思辨攻防」類知識點
* **適用互動**：說服力計量沙盤、論據類型分類、正反論點思辨卡片等。
* **設計原則**：引導學生分析論點的嚴密性與說服力，點對強力論據時說服力上漲通關。

## 📖 寫作手法解析規範
在撰寫任何寫作分析時，必須使用嚴謹、地道的國中修辭考點與文學理論，避免使用不成熟的或非教材觀念。

## 🎵 音效免檔案錯誤規範
使用 Web Audio API 生成音效，不依賴外部檔案，防範執行錯誤：
```javascript
function playQinSound(frequency) {
    if (!window.AudioContext && !window.webkitAudioContext) return;
    const ctx = new (window.AudioContext || window.webkitAudioContext)();
    const osc = ctx.createOscillator();
    const gain = ctx.createGain();
    osc.connect(gain);
    gain.connect(ctx.destination);
    osc.frequency.value = frequency;
    osc.type = 'sine';
    gain.gain.setValueAtTime(0.15, ctx.currentTime);
    gain.gain.exponentialRampToValueAtTime(0.01, ctx.currentTime + 0.8);
    osc.start();
    osc.stop(ctx.currentTime + 0.8);
}
```

## 🚀 交付流程
當觸發此技能時，請依照下列步驟進行：
1. **知識點提取**：深入閱讀用戶提供的課文與**講義/備課大綱**，精準提取出 3-5 個本課核心的**文意理解與寫作手法知識點**。
2. **動態關卡設計**：不生硬套用範本，而是針對提取出的知識點，動態設計出最合適、最好玩的互動版面。
3. 仿照 16:9 大字自適應排版架構，生成完整的單檔 HTML 檔案。
4. 執行 HTML 全域 `<div>` 標籤平衡檢測，確保無破損。
5. 部署並提供檔案庫網址與 Pages 預覽網址。
