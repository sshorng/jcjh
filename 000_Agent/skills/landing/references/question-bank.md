## 階段 A：活動與產品定位（4 題，全部必填）

### A1. 您要建立哪一種網頁？

```
A1. 您要建立哪一種活動/產品網頁？

💡 請選擇最符合的類型：
   1. 實體教育活動 / 親師座談會 / 公開授課（有日期時間、地點、限額）
   2. 線上家長資源 / 線上分享會 / 教學成果展（隨時可觀看、無日期限制）
   3. 數位教材包 / 段考自主學習單 / 國文講義（模板、電子教材、PDF、學習單）

🎯 你的答案（1 / 2 / 3）：___
```

**用途：** 決定硬資料區塊的欄位（實體活動要日期地點名額，數位教材包要格式/適用年級）。

AI 會自動翻譯成英文關鍵字去挑選設計風格。

## 階段 B：內容填入（10 題）

### B1. 一句話說清楚這個活動/教材能帶給學生或家長的改變？

```
B1. 一句話說清楚這個活動/教材能帶給學生的具體改變，或家長能獲得的幫助？
   （可加成效或時間更具體）

💡 重點：不是描述您的課程，是描述「參與後，學生/家長會有哪些改變」
   ✅ 「讓孩子在 3 堂課內學會解構文言文，克服對課外閱讀測驗的恐懼」（改變 + 具體成效）
   ✅ 「用 2 小時與導師深度對齊，掌握八年級學生的班級常規與段考學習策略」（改變 + 對象）
   ❌ 「八年級下學期第一次親師座談會」（只是活動名稱）
   ❌ 「提升學生國文程度與素養能力」（太過抽象）

🎯 你的答案：_______________
```

**對應區塊：** Hero 區大標題。
