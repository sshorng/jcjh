# Prepare Lesson (國文備課教材整理助手)

本技能旨在協助國中國文老師將任何白話文、文言文、新聞或文學材料快速整理為符合中學國文教學需求的「備課大綱」與「學生學習單」。

## 運作流程與指引

### 1. 學習語氣與風格
在開始編寫教材或學習單之前，請優先檢查並讀取 `200_Reference/writing-samples/` 下的 2-3 個範例文件（若有），了解老師的語意風格、排版偏好與題目設計邏輯。

### 2. 教材生成步驟
針對輸入的文章材料，依序生成以下內容：
1. **生字與注音**：篩選出文章中較難或關鍵的生字，標註教育部標準國語注音（注音符號），並給出正確字義解釋。
2. **段落大意與核心主旨**：精煉地概括文章的段落架構與核心思想。
3. **字詞註釋**：提取關鍵詞彙、成語或文言字詞，進行詳細註釋。
4. **文學賞析與引導思考**：深入解析文章的寫作修辭手法（如譬喻、借代、轉折等），並設計 2 題引導學生進行批判性思考的討論題。
5. **閱讀測驗題庫**：設計 3-5 題選擇題（包含標準答案與簡要解析），用以評估學生的閱讀理解能力。題型應分佈於「直接提取訊息」、「推論分析」及「詮釋整合」等不同難度層級。

### 3. 輸出規範與模板
請使用以下 Markdown 結構輸出，並寫入至指定路徑（預設存入 `100_Todo/projects/lesson-plans/` 目錄，命名為 `YYYY-MM-DD_課名或主題_學習單.md`）：

```markdown
# 國中國文學習單：[課名/文章主題]

## 一、 生字注音與詞語釋義
- **[生字 1]**（[注音]）：[解釋]
- **[生字 2]**（[注音]）：[解釋]

## 二、 段落大意與核心主旨
[大意與主旨說明]

## 三、 字詞註釋
1. **[詞彙 1]**：[解釋]
2. **[詞彙 2]**：[解釋]

## 四、 文學賞析與引導思考
### 寫作修辭賞析
[賞析內容]

### 引導思考討論題
1. [引導問題 1]
2. [引導問題 2]

## 五、 閱讀測驗與解析
1. [題目 1]
   (A) [選項A]
   (B) [選項B]
   (C) [選項C]
   (D) [選項D]
   - **標準答案**：[正確選項]
   - **解析**：[解析說明]

2. [題目 2]
   (A) [選項A]
   (B) [選項B]
   (C) [選項C]
   (D) [選項D]
   - **標準答案**：[正確選項]
   - **解析**：[解析說明]
```
