# 自學三 空城計 學思達教學講義

## 壹、暖身題

### 誰騙得了誰？

【活動名稱】：猜拳心理戰

【設計理念】：本課最大障礙是「學生不理解心理戰的運作邏輯」，難以體會司馬懿看到空城反而害怕的原因。此活動用猜拳讓學生親身體驗「預判對手的預判」——這是空城計的核心機制。

【與課文連結點】：暖身題建立的「預判對手性格→反其道而行」邏輯，直接對應 貳、三 中諸葛亮預判「司馬懿認為我謹慎→我故意不謹慎→他反而認為有詐」。

【活動內容】：
和隔壁同學玩三回合猜拳。第一回全力搶勝；第二回觀察對手習慣後再出；第三回連續三次出同一種拳。

| 回合 | 你的策略 | 對手反應 | 你贏了嗎？ |
|---|---|---|---|
| 1. 全力搶勝 | 猜他會出什麼？ | | |
| 2. 觀察後再出 | 你發現什麼習慣？ | | |
| 3. 故意重複 | 對手懷疑你在憋招嗎？ | | |

1. 第三回你故意連出同一種拳時，對手反而懷疑你「有陷阱」而換手——這和空城計中誰的處境最像？為什麼？

## 貳、課文理解與探究（基礎題）

### 一、開端：危機降臨（第一段）

【What：文意理解】

1. 諸葛亮為何陷入險境？請從第一段找出司馬懿率多少兵力、諸葛亮身邊有多少人，並算出雙方兵力差距。
2. 承接暖身題：司馬懿這時對諸葛亮的判斷是什麼？（提示：從他「蜂擁而來」的動作推測他認為自己穩操勝券。）

【How：寫作手法】

3. 作者用「蜂擁」形容司馬懿大軍、用「二千五百」交代諸葛亮兵力。這兩處細節合在一起讀，給讀者什麼感受？

【Why：作者意圖】

4. 作者為何不直接寫諸葛亮的對策，而是先鋪陳兵力懸殊？如果第一句就寫「諸葛亮胸有成竹」，故事的緊張感會怎樣？

#### 補充資料

**【街亭之戰】**
諸葛亮第一次北伐，馬謖不聽王平勸告在山上紮營，被司馬懿斷水源，蜀軍大敗。街亭一失，西城門戶大開。司馬懿率十五萬大軍、諸葛亮僅二千五百老弱殘兵，兵力比 60：1。

#### 教師引導

**【教師引導】** 第一段給我們兩個訊息。第一，馬謖失街亭讓諸葛亮陷入絕境——無險可守，敵軍已殺到門前。第二，作者故意不說諸葛亮有什麼對策，只寫了「分付」二字暗示他想到了辦法。這就是懸念：先告訴你問題有多嚴重，但不說解法，讓你想讀下去。「蜂擁」二字寫出敵軍鋪天蓋地之勢，「二千五百人」則凸顯蜀軍的微弱——兩者對比，讀者自然能感受到那種絕望。

#### 學習評量

**【學習評量】**
(    ) 1. 關於第一段，下列敘述何者正確？
(A) 馬謖守住街亭，諸葛亮安全無虞
(B) 司馬懿率十五萬大軍，諸葛亮僅二千五百人
(C) 諸葛亮立即下令全軍突圍
(D) 司馬懿軍隊因長途行軍而疲憊不堪

### 二、發展：從容布局（第二段）

【What：文意理解】

1. 諸葛亮下了哪四道命令？請依序列出，並說明這些命令違反了哪些「正常守城邏輯」。

【How：寫作手法】

2. 這一段全是短句：「藏旗幟」、「大開四門」、「扮百姓灑掃」、「登城操琴」。作者為什麼不用長句？短句連用帶來什麼節奏效果？

【Why：作者意圖】

3. 諸葛亮穿「鶴氅綸巾」、帶「二小童」、在城樓「焚香操琴」，傳遞了什麼共同訊息？如果他穿鎧甲拿寶劍，效果一樣嗎？為什麼？

#### 補充資料

**【鶴氅綸巾的象徵】**
「鶴氅」是鳥羽外衣，「綸巾」是青絲頭巾。這是諸葛亮「隱士軍師」的標誌裝扮，刻意營造超凡脫俗、從容不迫的氣質——等於在告訴司馬懿：「我根本不把你當一回事。」

#### 教師引導

**【教師引導】** 這四道命令的共同邏輯是「反常」。正常守城將領會關城門、備弓箭、激勵士氣；諸葛亮卻全反著來：藏旗（假裝沒軍隊）、開城門（假裝不設防）、百姓灑掃（假裝一切如常）、自己彈琴（假裝很悠閒）。目的只有一個：製造極度反常的景象，啟動司馬懿的懷疑機制。作者用短句，是因為短節奏快、不拖泥帶水，恰好表現諸葛亮下令的果斷——他幾乎瞬間就想好了全套劇本。

#### 學習評量

**【學習評量】**
(    ) 1. 諸葛亮的命令中，哪一道最可能讓司馬懿產生「不對勁」的懷疑？
(A) 將旗幟全部藏起來
(B) 大開西城四個城門
(C) 挑選百姓扮成士兵
(D) 在城樓上焚香操琴

### 三、高潮：心理較量（第三、四段）

【What：文意理解】

1. 司馬懿到城下看到了什麼？他做了什麼決定？請完成下列心理變化追蹤表：

| 階段 | 他所見到的景象 | 他的心理狀態 | 他的決定 |
|---|---|---|---|
| 聽聞斥候回報 | 報說「西城是空城」 | | |
| 親自到城下查看 | | 從懷疑變戒備 | |
| 看到諸葛亮彈琴 | 諸葛亮______ | | |

【How：寫作手法】

2. 作者讓司馬懿「看」了兩次，一次看城外（第二段末），一次看諸葛亮彈琴（第四段）。這兩次觀看的共同點是什麼？對情節推進有何作用？

【Why：作者意圖】

3. 司馬昭說「莫非無軍，故作此態？」——這其實是正確答案，但司馬懿「不聽」。作者這樣安排，暗示了司馬懿什麼性格特質？

#### 補充資料

**【司馬懿的認知陷阱】**
司馬懿與諸葛亮交手多年，對諸葛亮有一個根深柢固的判斷：「亮平生謹慎，不曾弄險。」因為諸葛亮謹慎，所以不可能開城門；既然開了，就一定有埋伏。他的推理沒有錯，但出發點被諸葛亮利用了。

#### 教師引導

**【教師引導】** 這一段是全文的核心。司馬懿的推理是：「亮平生謹慎，不曾弄險 → 今大開城門 → 必有埋伏。」這個邏輯鏈沒問題，問題在於出發點——司馬懿認定「謹慎的人絕不冒險」，但他沒想到諸葛亮正好利用這個認定來設局。因為你認為我謹慎，我偏偏做一件不謹慎的事，你就會自己嚇自己。空城計的高明不在騙眼睛，而在騙腦袋。司馬昭雖然說對了真相，但他年輕經驗不足，司馬懿不可能聽他的——這也符合司馬懿「多疑、只信自己判斷」的性格。

#### 學習評量

**【學習評量】**
(    ) 1. 司馬懿退兵的推理邏輯，下列何者最正確？
(A) 城門大開 → 諸葛亮投降 → 可能有詐 → 退兵
(B) 亮平生謹慎 → 不該開城門 → 開了必有埋伏 → 退兵
(C) 聽兒子司馬昭的話 → 覺得有理 → 撤退
(D) 看到諸葛亮彈琴 → 對手很從容 → 不敢打

### 四、結局：智者解密（第五、六段）

【What：文意理解】

1. 諸葛亮事後如何解釋他敢用空城計？請從課文中找出原話並用自己的話翻譯。
2. 司馬懿得知真相後說了什麼？這句話表達了什麼心情？

【How：寫作手法】

3. 諸葛亮「撫掌而笑」對比司馬懿「懊悔不已」——這種結尾寫法好在哪裡？

【Why：作者意圖】

4. 司馬懿說「吾不如孔明也」——他到底不如諸葛亮什麼？從全文來看，司馬懿輸的不是兵力也不是智力，那是什麼？

#### 補充資料

**【關鍵一句】**
諸葛亮：「此人料吾平生謹慎，必不弄險……吾非行險，蓋因不得已而用之。」
翻譯：司馬懿認為我這輩子小心謹慎、絕不冒險……我不是故意要冒險，是情勢逼得我不得不這麼做。

#### 教師引導

**【教師引導】** 結局兩個重點。第一，諸葛亮說「吾非行險，蓋因不得已而用之」——他不是要炫技，是被逼到絕路，只能賭司馬懿會上當。第二，作者用「撫掌而笑」和「懊悔不已」一輕一重的反應對比收尾，讓讀者清楚感受到「贏家從容、輸家後悔」。司馬懿說「吾不如孔明」——他不如的不是打仗本事，而是洞察人心的能力：諸葛亮贏在「我知道你怎麼想我，所以我利用你的想法來騙你」。

#### 學習評量

**【學習評量】**
(    ) 1. 諸葛亮說「吾非行險，蓋因不得已而用之」，這句話的正確解釋是什麼？
(A) 諸葛亮本來就喜歡冒險
(B) 諸葛亮在絕境中利用司馬懿對他的認知來設局
(C) 諸葛亮後悔使用了空城計
(D) 諸葛亮早就計畫好要騙司馬懿

## 肆、課後延伸

### 模組 A：跨文本閱讀理解

閱讀以下《孫子兵法》節錄，回答問題：

> **〈謀攻篇〉**
> 知己知彼，百戰不殆；不知彼而知己，一勝一負；不知彼不知己，每戰必殆。
>
> **〈虛實篇〉**
> 故善攻者，敵不知其所守；善守者，敵不知其所攻。……故形兵之極，至於無形。無形，則深間不能窺，智者不能謀。
>
> （白話翻譯：善於進攻的人，讓對手不知道該怎麼防守；善於防守的人，讓對手不知道該從哪裡進攻。……所以運用假象的最高境界，是讓對手完全看不透。一旦看不透，再厲害的間諜也無法窺探，再聰明的將領也無法應對。）

1. 【比較】〈謀攻篇〉說「知己知彼，百戰不殆」。諸葛亮在空城計中展現了哪些「知己」與「知彼」的行為？請從課文中各找一個例子。

2. 【評鑑】〈虛實篇〉說「形兵之極，至於無形」。你認為諸葛亮的空城計是否符合這個原則？請引用課文中的具體描寫來說明。

3. 【整合】如果你是指揮官，在「敵眾我寡」的情況下，除了空城計之外，還能如何運用「知己知彼」的原則來應對？請寫出一個你的策略。
