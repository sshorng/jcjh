# 自學三 空城計 學思達教學講義

## 壹、暖身題

### 誰騙得了誰？

【活動名稱】：猜拳心理戰

【設計理念】：本課最大障礙是「學生不理解心理戰的運作邏輯」，難以體會為什麼司馬懿看到空城反而害怕。此活動用猜拳遊戲讓學生親身體驗「預判對手的預判」——這是空城計的核心機制。

【與課文連結點】：暖身題建立的「預判對手性格→反其道而行」的邏輯，直接對應 貳、三 中諸葛亮預判「司馬懿認為我謹慎→我故意不謹慎→他反而認為有詐」。

【活動內容】：
和隔壁同學玩三回合猜拳。第一回合請盡全力贏；第二回合，請觀察對手習慣（他愛出什麼？）後再出拳；第三回合，請故意連續三次都出同一種拳。

| 回合 | 你的策略 | 對手的反應 | 你贏了嗎？ |
|---|---|---|---|
| 1. 全力搶勝 | 猜他會出什麼？ | | |
| 2. 觀察後再出 | 你發現了什麼習慣？ | | |
| 3. 故意重複 | 對手是否以為你會換？ | | |

1. 第三回合你故意連續出同一種拳時，對手反而懷疑你「一定在憋招」，最後換了手勢——這和空城計中誰的處境最像？為什麼？

## 貳、課文理解與探究（基礎題）

### 一、開端：危機降臨（第一段）

【What：文意理解】

1. 諸葛亮為什麼會陷入險境？直接原因「馬謖失街亭」造成了什麼後果？請從第一段找出司馬懿率領多少兵力、諸葛亮身邊有多少人。
2. 承接暖身題的「預判」概念：司馬懿這時對諸葛亮的判斷是什麼？（提示：從他「蜂擁而來」的動作推測他認為自己有絕對優勢。）

【How：寫作手法】

3. 作者用「蜂擁」來形容司馬懿的大軍、用「二千五百」來說明諸葛亮的兵力。這兩處細節分別製造了什麼效果？合在一起讀，給你什麼感受？

【Why：作者意圖】

4. 作者為何不直接寫諸葛亮的對策，而是先鋪陳兵力懸殊？如果第一句就寫「諸葛亮胸有成竹，已設下空城計」，故事的緊張感會怎樣變化？

#### 補充資料

**【資料一：街亭之戰】**
諸葛亮第一次北伐，派馬謖守街亭。馬謖不聽王平勸告，在山上紮營，被司馬懿斷水源，蜀軍大敗。街亭一失，諸葛亮所在的西城門戶大開。

**【資料二：兵力對比】**
司馬懿：十五萬大軍（先鋒）→ 諸葛亮：二千五百老弱殘兵 → 兵力比 60：1

#### 教師引導

**【教師引導】** 第一段告訴我們兩件事。第一，馬謖失街亭導致諸葛亮陷入絕境——西城無險可守，而司馬懿的大軍已經殺到門前。第二，作者刻意用「十五萬」和「二千五百」兩個具體數字，讓讀者立刻算出來兵力差六十倍，感受那種「完蛋了」的絕望。注意，文章不說諸葛亮有什麼對策，只寫他「分付」——這個動詞暗示他想到了辦法，但不說是什麼辦法，這就是懸念手法，讓你想繼續讀下去。

#### 學習評量

**【學習評量】**
(    ) 1. 關於第一段，下列敘述何者正確？
(A) 馬謖守住街亭，諸葛亮安全無虞
(B) 司馬懿率十五萬大軍，諸葛亮僅二千五百人
(C) 諸葛亮立即下令全軍突圍
(D) 司馬懿的軍隊因長途行軍而疲憊不堪

(    ) 2. 「司馬懿兵馬蜂擁而來」中「蜂擁」一詞的寫作效果是什麼？
(A) 形容軍隊像蜜蜂分工合作
(B) 表現敵軍數量龐大、氣勢洶洶，難以抵擋
(C) 暗示司馬懿軍隊紀律嚴明
(D) 說明軍隊行動快速但數量不多

### 二、發展：從容布局（第二段）

【What：文意理解】

1. 諸葛亮下了哪四道命令？請依序列出，並說明這些命令的共通點。
2. 諸葛亮自己的裝扮和行為是什麼？為什麼他要在城樓上「焚香操琴」？

【How：寫作手法】

3. 這一段全是動作短句：「藏旗幟」、「大開四門」、「扮百姓」、「登城操琴」。作者為什麼不用長句子來描寫？短句連用帶來了什麼節奏效果？

【Why：作者意圖】

4. 諸葛亮換上「鶴氅綸巾」、帶「二小童」、在城樓上「操琴」——這些行為傳遞了一個共同的訊息：我不在意。作者要讓讀者感受到的是什麼？如果諸葛亮穿鎧甲、拿寶劍，效果會一樣嗎？

#### 補充資料

**【鶴氅綸巾的意義】**
「鶴氅」是鳥羽外衣，「綸巾」是青絲頭巾。這是諸葛亮「隱士軍師」的形象標誌，刻意營造超凡脫俗、從容不迫的氣質——等於在告訴司馬懿：「我根本不把你當一回事。」

#### 教師引導

**【教師引導】** 這四道命令有一個共同邏輯：製造反常。正常的守城將領會做什麼？關城門、備弓箭、激勵士氣。但諸葛亮完全反著來：藏旗（假裝沒軍隊）、開城門（假裝不設防）、百姓灑掃（假裝一切正常）、自己彈琴（假裝很悠閒）。他的目的只有一個：讓司馬懿看到一個「完全不合理的景象」，從而啟動司馬懿的懷疑機制。作者用短句來寫，是因為短句節奏快、不拖泥帶水，恰好表現諸葛亮下令時的果斷——他幾乎沒有猶豫就完成了全套布局。

#### 學習評量

**【學習評量】**
(    ) 1. 諸葛亮的命令中，哪一道最能讓司馬懿產生「不對勁」的懷疑？
(A) 將旗幟全部藏起來
(B) 大開西城四個城門
(C) 挑選百姓扮成士兵巡邏
(D) 在城樓上焚香操琴

(    ) 2. 「披鶴氅，戴綸巾……焚香操琴」這段描寫，主要運用了哪種寫作手法？
(A) 對話描寫
(B) 動作與外貌描寫
(C) 內心獨白
(D) 景物烘托

### 三、高潮：心理較量（第三、四段）

【What：文意理解】

1. 司馬懿來到城下，他「看」到了什麼？請從課文中找出描寫他所見景象的句子。
2. 司馬懿的反應是什麼？他做了什麼決定？這個決定背後的推理邏輯是什麼？（提示：他用諸葛亮的哪個性格特質來推論？）

【How：寫作手法】

3. 作者讓司馬懿「看」了兩次——先看城外景象（第二段末），再看諸葛亮彈琴（第四段）。這兩次觀看的事件不同，但司馬懿的反應卻有什麼共同點？

【Why：作者意圖】

4. 司馬昭說：「莫非無軍，故作此態？」這句話其實是正確答案。但作者讓司馬懿「不聽」——這說明了司馬懿什麼性格特質？作者這樣安排，對故事發展有什麼好處？

#### 補充資料

**【司馬懿的認知陷阱】**
司馬懿和諸葛亮交手多年，他對諸葛亮有一個根深柢固的判斷：「諸葛亮一生謹慎，不曾弄險。」這句話成了他的思考鋼印——因為諸葛亮謹慎，所以不可能開城門；既然開了，就一定有詐。他的推理沒有錯，但起點錯了。

**【心理變化三階段】**
| 階段 | 所見 | 心理狀態 | 決定 |
|---|---|---|---|
| 聽聞 | 斥候回報「西城是空城」 | 懷疑 | 親自去看 |
| 親見 | 城門大開，百姓灑掃 | 從懷疑變戒備 | 決定退兵 |
| 確認 | 諸葛亮焚香操琴 | 確信有埋伏 | 下令速退，不聽司馬昭 |

#### 教師引導

**【教師引導】** 這一整段的核心只有一句話：「亮平生謹慎，不曾弄險。今大開城門，必有埋伏。」這是司馬懿的完整推理——他從「諸葛亮是謹慎的人」推到「他不可能冒險」，再推到「所以一定有詐」。這個推理在邏輯上是合理的，唯一的問題是：諸葛亮正好利用這個推理來設局。因為你知道我謹慎，所以我偏偏做一件不謹慎的事，你就會自己嚇自己。這就是空城計的精髓——不是騙你的眼睛，是騙你的腦袋。司馬昭雖然說對了「城中無兵」，但他年輕、經驗不足，司馬懿不可能聽他的，這也符合司馬懿多疑、只信自己判斷的性格。

#### 學習評量

**【學習評量】**
(    ) 1. 司馬懿退兵的推理過程，下列何者正確？
(A) 看到城門大開 → 判斷諸葛亮投降 → 怕有詐而退兵
(B) 諸葛亮一生謹慎 → 不該開城門 → 開了必有埋伏 → 退兵
(C) 聽兒子司馬昭的話 → 認為有理 → 決定撤退
(D) 看到諸葛亮在彈琴 → 覺得對手很從容 → 不敢進攻

(    ) 2. 司馬昭說「莫非無軍，故作此態？」作者安排這句話的用意是什麼？
(A) 表現司馬昭比父親聰明
(B) 暗示真相就在眼前，但司馬懿因性格偏誤無法接受
(C) 鋪陳司馬昭日後繼承父業
(D) 說明魏軍內部不合

### 四、結局：智者解密（第五、六段）

【What：文意理解】

1. 諸葛亮事後如何解釋他用空城計的原因？請從課文中找出那句話，用自己的話翻譯。
2. 司馬懿得知真相後的反應是什麼？他說了哪一句話？

【How：寫作手法】

3. 第五段寫諸葛亮「撫掌而笑」，第六段寫司馬懿「懊悔不已」——作者用這兩種反應來收尾，製造了什麼效果？這種結尾方式好在哪裡？

【Why：作者意圖】

4. 司馬懿說「吾不如孔明也！」——他到底不如諸葛亮什麼？從全文來看，司馬懿輸的不是兵力和智力，那是什麼？

#### 補充資料

**【關鍵一句話】**
諸葛亮：「此人料吾平生謹慎，必不弄險……吾非行險，蓋因不得已而用之。」
→ 翻譯：司馬懿料定我這輩子小心謹慎，絕對不會冒險……我不是故意要冒險，是因為情勢所逼不得不這麼做。

#### 教師引導

**【教師引導】** 結局有兩個重點你要記住。第一，諸葛亮說「吾非行險，蓋因不得已而用之」——空城計不是他故意要炫技，是被逼到絕路了，他只能賭司馬懿會上當。第二，作者用「撫掌而笑」和「懊悔不已」兩種完全相反的反應來收尾：贏的人輕鬆愉快，輸的人後悔莫及，讀者讀到這裡自然會想：「原來司馬懿被諸葛亮看透了！」司馬懿說「吾不如孔明」——他不如的不是打仗的本事，而是洞察人心的能力。諸葛亮贏在「我知道你怎麼想我，於是我利用你的想法來騙你」。

## 肆、課後延伸

### （一）延伸閱讀
- **《孫子兵法·謀攻篇》**：「知己知彼，百戰不殆」——諸葛亮正是用這句話打敗了司馬懿。
- **《三國演義》第九十五回**：「馬謖拒諫失街亭，武侯彈琴退仲達」——完整故事。

### （二）寫作引導

請以「一場____的對決」為題（自填形容詞），寫一篇記敘文，描述你親身經歷或觀察到的一場心理博弈。

**⚠️ 手法綁定**：請刻意運用本課的兩個核心寫作手法——(1) **對比描寫**（如強 vs 弱、從容 vs 緊張）；(2) **心理摹寫**（寫出內心變化，像課文寫司馬懿的三階段心理一樣）。

**寫作規劃矩陣（緊扣對比與心理摹寫）：**

| 段落 | 對比雙方狀態 | 內心摹寫重點 |
|---|---|---|
| 開端（衝突起點） | 對方的氣勢 vs 你的緊張 | 你當時在想什麼？ |
| 發展（對峙過程） | 誰佔上風？如何轉變？ | 哪一刻讓你最不安？ |
| 高潮（關鍵轉折） | 反敗為勝的瞬間對比 | 你做了什麼決定？ |
| 結局（收束反思） | 兩人的最終狀態對比 | 你學到了什麼？ |

**寫作大綱：**

| 段落 | 內容重點 |
|---|---|
| 破題 | 時間、地點、人物、對決性質 |
| 鋪陳 | 對方的優勢 + 你的不安心理 |
| 轉折 | 關鍵逆轉 + 強烈對比 |
| 收束 | 結局 + 你的體悟 |

### （三）參考範文（示範對比描寫與心理摹寫）

**一場沉默的對決**

隔著一張桌子，他翹著腳，微笑看我。那笑容像在說：你輸定了。

五分鐘前，我們為了誰可以先用電腦大吵一架。他是哥哥，向來比我會講話，每次爭論到最後，吃虧的一定是我。這次我靈機一動：「閉嘴比賽——誰先開口誰輸。」他聳聳肩：「隨便啊。」

（☞ 對比一：他從容 vs 我緊張）

比賽開始。他一直翹著腳看天花板，偶爾還哼歌。我卻心跳加速，不斷想：「他會不會突然說話？他是不是有什麼陷阱？」（☞ 心理摹寫）我的手心全是汗，但我不想讓他看出來，只好假裝專心看書。

第十分鐘，他打了一個哈欠。我注意到他打哈欠的時候，眉頭微微皺了一下——不對，他不是真的睏，他在裝。就像諸葛亮在城樓上彈琴，司馬懿以為他從容，其實他心裡也在緊張。原來他也沒有表面上看起來那麼輕鬆！（☞ 對比二：看穿對方的偽裝）

我坐直身子，慢慢地翻了一頁書，刻意讓紙張發出清脆的聲音。他的嘴角稍微僵了一下——他慌了。

第二十三分鐘，他終於開口：「好吧……你先用。」我忍住沒有笑出來。（☞ 對比三：我忍住笑 vs 他懊惱）

賽後我想，真正贏我的不是運氣，而是我看穿了他——就像諸葛亮看穿了司馬懿一樣。在心裡的戰場上，誰先看穿對方，誰就是贏家。（☞ 收束體悟：回應課文主旨）
